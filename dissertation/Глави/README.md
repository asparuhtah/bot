# Папка „Глави“

Тук слагаш черновите на главите като .md файлове. Скриптът:

- познава главата по името на файла (напр. `Гл3 Теоретичен анализ.md`, `Гл. 1.md`, `Увод.md`);
- брои думите в прозата (без заглавия и checkbox редове);
- ред `Цел: 8000` задава целеви брой думи за главата;
- ред `Статус: ...` добавя бележка, видима в таба „Глави“;
- checkbox списъци вътре (`- [x] ...`) обновяват задачите на същата глава.

Този README не се брои като глава.
