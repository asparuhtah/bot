# Транзиентен модел — стратификация на топлия буфер (setup)
**Дата:** 25.07.2026 · база: `R1_noHeatSink700iter.cas.h5` (гранично-задвижван, чилър външен) · метод по статията на Росен

> ⚠️ Транзиентът е ДРУГА физика от steady. Тук стратификацията ЩЕ заработи, защото добавяме плаваемост + гравитация + реални материали + транзиент. Steady не може по принцип.

---

## 0. Зареди базата
File → Read → Case: **`R1_noHeatSink700iter.cas.h5`** (само .cas; полето ще се re-инициализира).
Проверка: hw1 БЕЗ Qgen source, `hw_ret` студен обрат, затворени вериги (target mass flow). Това е правилната структура.

---

## 1. Solver → Transient
Physics → General → Time → **Transient**.
(Pressure-based, Coupled или SIMPLE — за транзиент SIMPLE често е по-стабилен; започни със SIMPLE.)

## 2. ⭐ Плаваемост — БЕЗ това няма стратификация
Materials → **water-liquid** → Density → смени `constant` на:
- **Опция A (по-просто): Boussinesq**
  - Density (ρ₀) = **998.2 kg/m³**
  - Добави **Thermal Expansion Coefficient** = **4.5e-4 [1/K]** (представителна за 40-75°C; варира 4e-4@40°C … 5.8e-4@70°C)
- **Опция Б (по-точно за широк диапазон): piecewise-polynomial ρ(T)** — таблица плътност на водата по температура. Ползвай ако диапазонът е >40K (39→88°C като Росен).

Започни с **Boussinesq** (стандарт за стратификация, валиден щом β·ΔT<<1: тук ~0.02 ✓).

## 3. ⭐ Гравитация — БЕЗ това плаваемостта не действа
Physics → Operating Conditions:
- Чекни **Gravity**.
- Gravitational Acceleration = **−9.81** в **вертикалната ос** на буфера (Y или Z — провери ориентацията на геометрията! буферът е вертикален, H>>D).
- **Operating Temperature** = референтната T₀ за Boussinesq = началната средна температура (напр. **312K** ако следваш Росен).

## 4. Реални буферни материали
Materials → буферните солиди (`steel_superconductive` k=50, copper):
- Смени на **реална стомана** (k≈16 W/mK неръждаема, или ≈50 въглеродна) с **реални ρ, cp** (стомана ρ≈7850, cp≈470).
- Целта: солидите да са топлинна маса, НЕ хомогенизатори на температурата. Високата проводимост убива термоклина.
- Ако солидите са само тънки стени → ефектът е малък; ако са големи обеми → критично.

## 5. Гранични условия — ВИСОЧИНАТА е ключова за термоклин
Принцип: **горещо ГОРЕ, студено ДОЛУ** (иначе нестабилно смесване).
- **Соларно зареждане (горещо):** през **`up_inlet`** (връх на буфера), НЕ down_inlet. Горещо на дъното плува нагоре и размесва.
- **Студен обрат от чилъра:** през нисък порт (`hw_ret` или `down_inlet` — виж кой е долу).
- **Изтегляне към чилъра (горещо):** от висок порт (`hw_sup` близо до върха).
- Провери височините на портовете в геометрията (Discovery/plane) и ги мапни: горещи входове/изходи горе, студени долу.
- Дебит: 0.1357 kg/s (~490 л/ч) като Росен, или твоят.

## 6. ⭐ Транзиентна зареждаща температура (функция на времето)
Зареждащият вход → Thermal → Total Temperature → **Expression**:
- **По Росен (бенчмарк):** `0.0029[K/s] * flow-time + 340.22[K]` (солар 67→88°C за 7200s).
- **Твой сценарий:** почасов профил (Profile от .csv, или piecewise expression по flow-time за целия ден).

## 7. Инициализация — началното състояние
Standard Initialize → после **Patch** еднородна температура:
- Всички зони → **312K (39°C)** (началото по Росен), или твоето начално състояние (частично зареден буфер).
- Студен разреждащ вход: **283.15K (10°C)** по Росен.

## 8. Time step + прогон
Run Calculation:
- **Time Step Size:** ~**2-5 s** (базирано на времето на престой ~20s; по-малко = по-стабилно/точно).
- **Number of Time Steps:** за целия цикъл. Росен: 7200s → при dt=5s = **1440 стъпки** (или dt=2s = 3600).
- **Max Iterations/Time Step:** ~**20-30** (да сходи всяка стъпка; гледай residual да пада в стъпката).
- Autosave every ~50-100 стъпки, prefix `Transient_strat_`.

## 9. Мониторинг на стратификацията (както Росен — точки по височина)
Създай **точкови повърхности на 5-6 височини** в буфера (Surface → Point, по вертикалната ос):
- Report Definitions → Surface Report → Area/Vertex Average на Static Temperature на всяка точка.
- Report Plots → температура vs време на всяка височина → **показва как термоклинът се гради/движи**.
- Плюс: средна температура на обема (Volume Average), COP (`COP_expr`/`COP_CFD`).

## 10. Визуализация (след прогона)
- Contour Static Temperature на вертикална равнина, **стеснена скала** (Min/Max = реалния обхват, не глобален) → термоклинът.
- Vectors по температура + Pathlines → циркулацията/плаваемите струи.
- Animation през стъпките → еволюцията на термоклина (Solution Animations → всяка N стъпки).

## Sanity checks / gotchas
1. **Без Boussinesq/ρ(T) → нулева плаваемост → стратификация НЕВЪЗМОЖНА.** Провери, че density НЕ е constant.
2. **Гравитацията в правилната ос** (вертикалната на буфера) — иначе термоклинът е накриво или го няма.
3. **Горещо горе, студено долу** — обратното (горещо долу) е нестабилно, размесва.
4. **Time step да не е твърде голям** — иначе термоклинът се „размазва" числено. Провери Courant/residual в стъпката.
5. **Реални материали** — superconductive солиди хомогенизират, махни ги.
6. Транзиентът е БАВЕН (много стъпки) — пусни за нощта, autosave често.
7. Сравни складираната енергия Q=m·cp·(T_край−T_начало) с очакваното (Росен: 25.1 kWh за неговите условия).

## Ред на действие (обобщено)
1. Зареди `R1_noHeatSink700iter.cas`.
2. Transient + Boussinesq (β=4.5e-4) + Gravity (вертикална ос, T₀=312K) + реални материали.
3. BC: горещо зареждане горе (up_inlet, T=f(time)), студено долу.
4. Initialize + patch 312K (39°C).
5. Точкови монитори по височина + средна T + COP.
6. dt=2-5s, ~1440-3600 стъпки, 20-30 iter/стъпка, autosave.
7. Първо възпроизведи бенчмарка на Росен → после твоите сценарии.

*За transient фазата на дисертацията. Steady R1/R2 са затворени (COP 0.60).*
